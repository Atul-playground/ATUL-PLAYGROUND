# ATUL(PLAYGROUND)

A proper project structure for the ATUL personal productivity playground.

## Folder map

- `index.html` — app entry point
- `src/main.js` — app behavior and UI
- `src/style.css` — visual design
- `supabase/schema.sql` — future cloud database structure
- `public/` — static assets

## Run locally

1. Install Node.js.
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local address Vite prints.
